# M5 synthetic fixtures

These fixtures are hand-specified examples, not evaluator data or a live-feed schema. `config.json` selects an explicit namespace, first offset and 1,800-second synthetic lateness allowance. Its SHA-256 covers the exact bytes of `provinces.json`, including its newline. This one-row synthetic province table is not a production geography artifact.

`bridge.jsonl` has five detections along the equator at longitudes 0, .002, .018, .020 and .010 degrees. AB and CD initially form separate pairs; A/B use the same satellite. Adjacent bridge gaps are .008 degrees (about 891 m), below 1 km. The .016-degree gap between pairs is above 1 km. All acquisition times differ by at most four minutes. E joins the pairs at offset 5; removing E at offset 6 restores CD and leaves AB's identity on AB. `bridge.expected.json` fixes memberships, singleton counts and independently hashed source IDs. The expected centers are .001 for AB, .019 for CD and .010 for ABCDE. FRP totals are 20, 20 and 50 MW; severities are WASPADA, WASPADA and SIAGA.

`identity.expected.json` uses Python's standard JSON encoding (`ensure_ascii=False`, compact separators) and hashlib to calculate expected identity digests independently of the Go implementation. It includes HTML characters, U+2028, lexical zero/time forms and canonically equivalent Unicode strings that must remain distinct.

`mixed-merge-split.jsonl` is an eight-operation open-case reproduction. Before the final update ABCDE and FG are active. Moving C from .010 to .028 produces AB and DECFG: A's old identity splits while the right child merges with the other predecessor. The agreement does not settle identity precedence for that combined transition. Expected: `ambiguous_merge_split`, no affected intents, unchanged settled fire state and accepted input frontier 8. The CLI exits nonzero. This is an explicit blocked design case; it is not a failed geodesic or an invented survivor rule. The library test adds a disjoint pair afterward and verifies that it can emit independently.

Additional literal test vectors in the reference package cover confidence, stale/conflicting delivery, UTC/lexical parsing, distance/time/FRP boundaries, Kahan summation, date-line/degenerate centers, province ties, late anchors and all shared restoration fixtures. The equatorial distance oracle uses WGS84's 6,378,137 m semimajor axis. A separate rounded Wellington–Salamanca distance comes from [GeographicLib's published example](https://geographiclib.sourceforge.io/html/python/examples.html), not from this implementation. None of the numerical test tolerances changes the graph predicate.
